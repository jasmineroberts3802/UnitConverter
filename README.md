## 7. Submitting the project

When submitting your project to Blackboard, run this command to create an archive:

```bash
git archive HEAD -o <yourname>-UnitConverter.zip
```

This will create a zip file of the project as it is currently committed in git, which excludes everything in the .gitignore file.
